# ADR-0001：首版采用单房间、单用户、无副作用边界

## 状态

已接受（2026-08-16）

## 背景

家庭语音助手同时涉及持续录音、真实世界工具、长期记忆和多人隐私。若第一版同时接入多房间、多用户和智能家居写操作，问题无法被单独验证，也会显著扩大隐私风险。

## 决策

首版只支持一个已授权用户、一个房间，并限制为对话、记忆检索/写入与只读工具。所有有现实世界副作用的工具均暂不接入。

未唤醒的音频不应离开设备；实时会话和长期记忆必须有独立的状态与保留策略。

## 后果

可以先把唤醒、打断、会话关闭和记忆质量做成可测量的闭环；代价是暂时不能以“小爱同学完整替代品”的范围宣传或验收。
