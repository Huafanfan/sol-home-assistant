# 腾讯云语音层（首版）

## 范围

腾讯云仅承担实时语音识别（ASR）与实时语音合成（TTS）。它不拥有 Sol 的长期记忆、工具权限或文本推理决策；这些能力仍由 Voice Gateway 管理。

- 输入路径：本地唤醒与 VAD 完成后，Gateway 才把音频流发送给腾讯云 ASR。
- 输出路径：Gateway 取得回答文本后，以流式片段发送给腾讯云 TTS 并立即播放。
- 取消：用户打断时，Gateway 必须同时停止本地播放和未完成的 TTS；仍在运行的文本推理请求也应被取消或忽略。

腾讯云提供独立的实时 ASR WebSocket 接口与实时 TTS WebSocket 接口，适合保留本项目自己的会话、记忆和路由边界。

## POC 选择

- ASR：先用标准实时 ASR 消耗免费额度，同时以相同测试集评估大模型 2.0 版的准确率、方言表现、首个结果延迟和噪声鲁棒性。
- TTS：先用精品音色完成闭环；若体验明显受限，再评估大模型音色。超自然大模型音色不作为默认项。
- 并发：单房间、单用户 MVP 使用默认并发，不购买并发叠加包。

实际引擎名、音色 ID、采样率和地区应由部署时的控制台配置决定，不能在代码中假定或硬编码。

## 成本护栏

以下是 2026-08-16 的官方价格快照，只用于预算，不作为程序常量：

| 能力 | 家用低用量单价 | 免费额度 |
| --- | ---: | --- |
| 标准实时 ASR | ¥3.20 / 小时（后付费首档） | 每月 5 小时 |
| 大模型 2.0 实时 ASR | ¥1.00 / 小时 | 无 |
| 精品 TTS | ¥0.30 / 万字符 | 一次性 800 万字符，3 个月有效 |
| 大模型音色 TTS | ¥1.20 / 万字符 | 一次性 10 万字符，3 个月有效 |

家庭用量应先按后付费关闭或明确的硬限额运行，并在腾讯云控制台设置余额/资源包告警。若免费额度或资源包耗尽，系统应给出“语音服务暂不可用”的本地反馈，而不是无限重试或持续录音。

## 验收数据

对每轮会话只记录脱敏的技术指标，不记录原始音频或完整转录：

- ASR 首个结果与最终结果延迟；
- 文本推理首字节延迟；
- TTS 首个音频包延迟；
- 唤醒漏检、误唤醒和打断成功率；
- 提供方错误码、重试次数、累计音频秒数与累计合成字符数。
